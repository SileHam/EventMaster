# EventMaster

Academic event-management application with a Django API and React frontend.

## Local use

The `backend/` directory contains the Django API and `frontend/` contains the React client.
Install Python packages from `backend/requirements.txt` and frontend packages using `npm ci`.
Configure a local `backend/.env`, run Django migrations, and start the API and Vite client.
Local database contents and environment files are intentionally excluded.
